# 2026–2027 Season — BIOGLOW™

Season notes for the FIRST LEGO League Challenge **BIOGLOW** robot game (part of FIRST CANOPY). Rainforest / biodiversity theme.

> These are our working notes, not the rulebook. The official [Robot Game Rulebook](links.md) is always the authority — check [Challenge Updates](links.md) before every event, since scoring clarifications get posted there during the season.

## Robot game format

- **15 missions** on one mat.
- **3 matches**, each **2.5 minutes**, autonomous. Only the **best** single match score counts toward awards/advancement.
- Robot launches from one of two launch areas inside **Home** (Left / Right), returns to Home between runs.
- This is the **final season** SPIKE Prime robots are allowed.

## Points that aren't missions

| Source | Points | Notes |
|---|---|---|
| Equipment inspection | **20** | If *all* equipment fits in a single launch area, under 12 in (305 mm) tall |
| Precision Tokens | up to **50** | Start with 6. Each interruption outside Home costs one. End-of-match: 1→10, 2→15, 3→25, 4→35, 5→50, 6→50 |
| Gracious Professionalism | 2 / 3 / 4 | Added to Core Values score, not the robot game score. Default is 3 (ACCOMPLISHED) |

## Equipment limits (from the rulebook)

- **1 controller** max (SPIKE Prime / Essential / EV3 / Robot Inventor / Powered Up / NXT / RCX).
- **4 motors** max, any mix.
- Sensors: **touch/force, color, distance/ultrasonic, gyro** only — any number.
- One power pack or 6 AA; one microSD card.
- All pieces LEGO, factory condition (string and pneumatic tube may be cut).
- The Mission 13 keystone species model **counts as equipment** and is inspected.

## New this year — interchangeable docks

Missions **13, 14, 15** use three swappable docks: **mine**, **city**, **farm**. Your team chooses which of the three models sits on each dock before the match — this is a strategy decision (see [strategy.md](strategy.md)). Mission 15's environmental bonus depends on the model matching the dock's "greatest ecological need".
